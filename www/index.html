Error Codes
400
Bad Request

Simulate a malformed request frame parsing syntax failure.
403
Forbidden

Access secure local zones protected by server rule restrictions.
404
Not Found

Simulate a malformed request frame or a syntax parsing failure.
405
Method Not Allowed

Send a request method (like POST) to a route that restricts it.
413
Payload Too Large

Exceed your configured client_max_body_size.
415
Unsupported Media Type

Send a POST request with an unsupported Content-Type header.
500
Internal Error

Simulate unexpected CGI background sub-process crash loops.
501
Not Implemented

Requests an unimplemented HTTP method like PUT or PATCH
505
Version Not Supported

Triggered by sending a request using a version other than HTTP/1.1
