🚀 About This Project

Welcome to this tiny experiment running inside a Docker container powered by NGINX.

This project is not a real website… it's a playground 🧪 where we break things, fix them, and try to understand how web servers actually work.

⚙️ What is this?

  • A static website served by NGINX
  • Running inside a Docker container
  • A place to learn how HTTP requests behave

🔥 Fun fact

Every time you refresh this page, somewhere a log file gets updated 📡

😄 Why does this exist?

Because learning infrastructure is more fun when you can actually break it.

Built with curiosity, Docker, and a bit of chaos.
